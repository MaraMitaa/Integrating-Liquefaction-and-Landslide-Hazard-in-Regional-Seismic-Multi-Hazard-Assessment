This repository contains the site model files used in the study "An Integrated Framework for Regional-Scale Assessment of Earthquake-Induced Landslides and Soil Liquefaction".
The repository includes the following files:
- Liquefaction_500m_filtrato_vs30_esrm.csv: Regional site model used for earthquake-induced soil liquefaction analyses. It is defined on a regular grid with a spatial resolution of 500 m and includes the input parameters described in Section 3.3 of the manuscript.
- PTav.csv: Regional site model used for the earthquake-induced landslide analyses. It is defined on a regular grid with a spatial resolution of 250 m and includes the input parameters described in Sections 3.3 and 4.2 of the manuscript.
- PT1.csv, PT2.csv, PT3.csv, PT4.csv: Regional site models used for the earthquake-induced landslide sensitivity analyses, as described in Section 4.3 of the manuscript.
